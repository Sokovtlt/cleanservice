# Cleanservice
This web-site collects clean service order. As administrator you can add different things and clothes to database. Users choose 
what they would like to clean and see how much are cost.


## Content
- [Start](#start)
- [Technologies](#tech)


## <a id="start">Start</a>
To run the application, download the project files and static files from 
[here](https://drive.google.com/file/d/1ew3mKiVWpxtODSxxzoPFdfnpUIDc1CkL/view?usp=sharing). Put folder with static files
to directory 'app'.
Open the terminal from the project's root directory, and enter the command:


```sh
$ docker-compose up -d --build
```


### <a id="tech">Technologies</a>
For the installation and launch of the project, you need [Docker](https://docker.com/).
This project uses Python 3.11, Django 4.2, JavaScript.
